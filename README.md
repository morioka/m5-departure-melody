# M5Stack 発車メロディー再生装置

M5Stack CoreS3-SE と、ONで接点が閉じて保持され、OFFで接点が開く押ボタン開閉器を使う、SDカード式の音声再生装置です。

駅名と音声ファイルの対応は `stations.csv` で管理します。駅数はプログラムに固定せず、CSVのデータ行数に応じて変化します。画面にON/OFFのテストボタンがあるため、実物スイッチをまだ接続していなくても、音声再生や割り込みを試験できます。

> **動作確認状況**: CoreS3-SEで基本的な画面表示と音声再生が確認されています。ただし、このリポジトリに収録したコード全体のコンパイル・総合動作確認を保証するものではありません。SD読み込み、長い音声の割り込み、GPIO入力とタッチ操作の組み合わせは実機で確認してください。

## 主な機能

- SDカード上のCSVから駅名・3種類の音声ファイルパスをロード
- CSVの駅数に合わせた駅選択（前・次で循環）、選択時の駅名チャイム再生
- 選択した駅の `name.wav` / `on.wav` / `off.wav` を再生
- 画面上の「ON テスト」「OFF テスト」でも物理スイッチと同じ再生処理を実行
- 音量ボタンで `160 → 220 → 255 → 160` を循環（起動時160）
- 別の音声を選ぶと、現在の再生を停止してから新しい音声へ切り替え
- 起動時に参照先の音声ファイルの存在を確認し、欠落数を警告
- 設定ファイルの不正は行番号を示して起動停止、個別音声の欠落・異常は操作を継続

## ハードウェア

| 部品 | 用途 |
| --- | --- |
| M5Stack CoreS3-SE | 画面、タッチ入力、microSD、内蔵スピーカー |
| microSDカード（FAT32） | 駅設定とWAV音声を保存 |
| Grove 4ピンケーブル | CoreS3-SEの側面PORT.Aへ接続 |
| Grove用ネジ端子基板など | Groveケーブルと実物スイッチの電線を接続（任意） |
| 春日電機（パトライト） BSW215B3 | 動力用押ボタン開閉器（一般防雨形）。ONで保持、OFFで解除する接点を使用 |
| USB-Cデータケーブル、5V USB電源 | 書き込み、電源供給 |
| パネルマウント板 | 展示板への取り付け（任意） |

Arduino、DFPlayer Mini、外付けプルアップ抵抗、ブレッドボード、背面M-Bus接続は必要ありません。音声は内蔵スピーカーから出します。

### 使用している実物スイッチ：BSW215B3

- **メーカー**：春日電機（パトライト）
- **型式**：`BSW215B3`
- **品名**：動力用押ボタン開閉器（小型電動機等の直接操作用・一般防雨形）
- **構造**：黒色のONボタンと赤色のOFFボタンを備え、ON操作で接点が機械的に保持され、OFF操作で保持が解除される形式
- **仕様**：3極・15A、接点構成3a、保護等級IP64（一般防雨形）
- **製品情報**：[ミスミの商品ページ（型式 BSW215B3）](https://jp.misumi-ec.com/vona2/detail/222000150507/?HissuCode=BSW215B3)

本来は電動機の電源回路を開閉する部品ですが、**この製作では電動機も商用電源も接続せず、3極のうち1極の接点のみをGPIO用の無電圧スイッチとして利用**します。従ってM5Stackとの結線は2本で足ります。使用する端子の組は実物の端子表示・導通測定で確認してください。接点には外部電圧を加えません。

### スイッチの結線（2線）

```text
CoreS3-SE 側面 PORT.A             実物スイッチ（無電圧・保持接点）
GPIO1 / SCL  -----------------  接点の片側
GND          -----------------  接点のもう片側

GPIO2 / SDA  未接続
5V           未接続・端末を絶縁
```

- `pinMode(1, INPUT_PULLUP)` で内部プルアップを有効にします。
- ON時：接点が **閉** → GPIO1が **LOW** → ON音声を一度再生。
- OFF時：接点が **開** → GPIO1が **HIGH** → 再生中のON音声を止めてOFF音声を再生。
- 接点を保持している間は再生命令を繰り返しません。音声はファイルの終わりで停止します。
- 状態変化を30ms安定させてから検出します（チャタリング対策）。
- **起動時は現在の接点状態を読み取って待機し、ON/OFF音声を自動再生しません。** 次に接点が変化した際に再生します。

**安全上の注意：** 接続可能なのは、M5Stack以外の電圧がかかっていない無電圧接点だけです。照光部や外部電源端子に接続しないでください。実機はテスターで導通を確認し、PORT.Aの刻印・ケーブルの各線とネジ端子の対応を必ず確認してください。線の色だけで判断しないでください。PORT.AのGPIO1はI²CのSCLと兼用なので、ここをスイッチ用に使っている間は別のI²C機器と共用しません。

## 画面操作

CoreS3-SEのタッチ画面（320×240）を横長で使います。コードは `M5.Display.setRotation(0)` です。

```text
┌────────────────────────────────────┐
│ 発車メロディー     01/16  VOL 160  │
│                                    │
│               東京                 │
│             待機中                 │
│                                    │
│   [前]        [駅名]       [次]    │
│                                    │
│   [ON テスト]      [OFF テスト]     │
└────────────────────────────────────┘
```

| 操作 | 動作 |
| --- | --- |
| 前 / 次 | 選択駅を循環させ、その駅名音声を再生 |
| 駅名 | 現在の駅名音声を再生 |
| ON テスト / OFF テスト | 対応する音声を再生（GPIO未接続でも使用可能） |
| VOL | 音量160、220、255を順次切り替え |
| 物理スイッチのON / OFF | 接点の閉 / 開の変化で対応する音声を再生 |

画面上のON/OFFは**再生テスト用**です。画面操作で物理スイッチの接点状態を変更したり、保持状態を記憶したりはしません。

## リポジトリ構成

```text
.
├── README.md
├── .gitignore
├── LICENSE                     # MIT License（ソースコード等）
├── m5_departure_demo/
│   └── m5_departure_demo.ino   # Arduino IDEで開く
└── sdcard/                      # 中身をmicroSDのルートにコピー
    ├── stations.csv
    └── sounds/
        ├── tokyo/
        │   └── .gitkeep       # Gitで空ディレクトリを維持
        ├── shinagawa/
        │   └── .gitkeep
        └── ...                 # CSV記載の全駅分
```

**音声WAVファイルはリポジトリに同梱しません。** Gitは空ディレクトリを管理しないため、各駅フォルダに `.gitkeep` を置いています。音源は各自で用意して `name.wav` / `on.wav` / `off.wav` の名前で該当する駅フォルダへ配置してください。`sdcard/` フォルダ自体はコピーせず、その**中身**をmicroSDカードの最上位にコピーします。`.gitkeep` はSDカードにコピーしても動作に影響しません。

**重要：** 配布時点では全WAVが欠落しています。このまま起動すると音声ファイル欠落の警告が出ます。これは想定動作です。駅名表示やタッチ操作は試せますが、再生にはWAVの追加が必要です。

## 駅の設定（stations.csv）

UTF-8テキスト、ヘッダーを含む4列です。

```csv
name,name_wav,on_wav,off_wav
東京,/sounds/tokyo/name.wav,/sounds/tokyo/on.wav,/sounds/tokyo/off.wav
品川,/sounds/shinagawa/name.wav,/sounds/shinagawa/on.wav,/sounds/shinagawa/off.wav
```

- 1行が1駅です。駅番号と並び順はCSVの順序に従います。固定の16駅制限はありません。
- `name` が画面上の表示名です。各パスはSDカードのルートからの絶対パス（`/` で始める）にしてください。
- 空行と先頭が `#` のコメント行は読み飛ばします。
- 空の項目、不正なヘッダー、列数違い、`/` で始まらないパス、駅0件は起動エラーです。
- **単純なCSVパーサー**なので、ダブルクォートによるエスケープや、項目内のカンマは扱えません。駅名は日本語でも構いません。
- 駅数や音声を変更した場合、SDカードのファイルを更新して本体を再起動してください。コードの再書き込みは不要です。

## WAVの条件と音声ファイルの準備

この実装はWAVを**ファイル単位でPSRAMに読み込んで**から再生します。

- 推奨形式：PCM、16bit、モノラル、16kHz
- 現コードのサイズ上限：**1ファイル3MiB**（`MAX_WAV_BYTES`）
- RIFF/WAVEヘッダーとファイルサイズを簡易チェックし、実際のデコードはM5Unified側で行います。
- **WAVの実体はリポジトリに含まれません。** CSVで指定した各駅ディレクトリに、再生する3つのWAVを自分で配置してください。
- 16駅×3ファイルで48個となります。10秒の16kHz・16bit・モノラルWAVを48本用意した場合、合計約15.4MBです（駅名を短くすればさらに小さくなります）。70MB程度の空き容量でも十分収まります。

実際の発車メロディーなどに差し替える場合は、楽曲（作曲・編曲）、録音物（原盤・実演等）、アナウンス音声などの権利と利用条件を個別に確認してください。私的な試聴、学園祭での再生、インターネット公開・再配布では、必要な許諾・手続きが異なる場合があります。

## Arduino IDEでの導入（Windows）

1. [Arduino IDE 2.x](https://www.arduino.cc/en/software/) をインストールします。
2. Arduino IDEの**ファイル → 基本設定**から、追加のボードマネージャURLに次を登録します。
   `https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json`
3. **ボードマネージャ**で `M5Stack` のボードパッケージをインストールします。
4. **ライブラリマネージャ**で `M5Unified` をインストールします（必要な依存ライブラリも導入）。
5. `m5_departure_demo/m5_departure_demo.ino` を開きます。
6. ボードとして **M5CoreS3** を、接続したUSBポート（例：`COM5`）を選びます。USB-Cケーブルはデータ通信対応品を使います。
7. 最初に **✓ 検証** でコンパイルし、成功したら **→ 書き込み** を行います。ポートや書き込みに問題があれば、CoreS3-SEの公式手順に従ってダウンロードモードに切り替えます。
8. microSDカードをFAT32で用意し、各駅の音声WAVを `sdcard/sounds/` 以下に配置してから、`sdcard/` の中身をカードの最上位にコピーします。
9. microSDを本体に挿入して再起動します。画面で駅選択やON/OFFテストを試します。
10. 最後に実物スイッチをPORT.Aに接続し、接点の開閉による再生を確かめます。

プログラムを一度書き込んだ後は、USB給電だけで動きます。**CoreS3-SEには内蔵バッテリーがありません**。

公式資料：[CoreS3-SE](https://docs.m5stack.com/ja/core/CoreS3-SE) / [M5Unified](https://github.com/m5stack/M5Unified)

## 動作確認のチェック項目

1. スイッチ未接続で起動し、CSVの駅名と現在駅番号が表示される。
2. 「前」「次」で駅が切り替わり、駅名チャイムが鳴る。
3. 「ON テスト」を押し、約3〜5秒後に「OFF テスト」を押して、ON音声が途中で止まりOFF音声に切り替わる。
4. OFF再生中にONテストを押して逆方向も試す。
5. 「VOL」で160→220→255→160と切り替わる。
6. WAVが未配置なら欠落数が表示される。正しくWAVを配置してから起動すると警告がなくなる。WAVを1つ退避するとその分だけ欠落が検出される。
7. GPIO1-GNDの保持接点を閉じる／開くとON／OFF音声が鳴る。再度閉じてもONが鳴る。

## エラー時の動作

| 状況 | 挙動 |
| --- | --- |
| SD未挿入、初期化失敗 | エラー表示して停止。再起動が必要 |
| stations.csvなし、CSV不正、駅データなし | エラー表示して停止。CSVの不正は行番号と理由を表示 |
| 個別のWAV欠落 | 起動時に欠落数を表示、動作は継続。欠落パスはシリアル出力 |
| 欠落WAVを選択 | 現在の音声を止めて「音声ファイルなし」を表示 |
| WAVサイズ異常、ヘッダー異常、読み込み失敗 | 再生せずエラーを表示し、操作は継続 |
| 再生が最後まで完了 | 表示を「待機中」に戻す |

シリアルモニターは **115200 baud** で確認できます。カードを差し替えた場合、ホットリロードはしません。再起動してください。

## 制約・注意事項

- 長いWAVをSDからストリーミングする方式ではなく、再生前に全体をメモリへロードする方式です。
- 画面は横長の固定レイアウトです。長すぎる駅名や非常に多い桁数の駅番号は見切れる場合があります。
- 動的駅数はメモリに収まる範囲で対応します。非常に多い駅数での実機動作は未検証です。
- ファイル存在チェックは完全な音声デコード検査ではありません。
- 実物スイッチの接点は機種によって構造が異なります。本設計の2線方式はONで閉を保持、OFFで開になる場合に限ります。
- `cc1plus.exe: out of memory` は通常、**開発用PCのコンパイル処理におけるメモリ不足**を示し、CoreS3-SE本体のメモリ不足とは別です。並列コンパイル数の制限やPC側の空きメモリを確認してください。
